# 🎓 Student Record Management System (Python)

A console-based Student Record Management System built in Python to practice Object-Oriented Programming (OOP), modular programming, and JSON file handling.

## ✨ Features

- Add Student
- Search Student
- Update Student
- Delete Student
- View All Students
- Count Students
- Persistent JSON Storage

---

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- JSON File Handling
- Modular Programming
